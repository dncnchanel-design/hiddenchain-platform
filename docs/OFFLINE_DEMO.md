# 非生产：隐链明算离线答辩演示

> 仅用于 development/test。不得连接生产数据库、使用生产口令或作为安全能力证明。

## 适用场景

用于现场答辩、展台展示和无网络环境演示。平台在答辩电脑本机运行，不需要服务器、域名或公网隧道。

## 一键启动

在项目根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\start-offline-demo.ps1 -OpenBrowser
```

浏览器会打开：

```text
http://127.0.0.1:5173/login
```

演示账号：

```text
exchange / exchange123
```

## 答辩前检查

1. 在答辩电脑执行一次启动脚本，确认登录、可信调用验证、隐私计算、能源场景验证、链上存证和监管审计可完整演示。
2. 关闭浏览器后再次启动，确认运行数据与演示流程正常。
3. 准备关键流程录屏和 PPT 截图，作为突发故障备份。
4. 现场不依赖 Wi-Fi；若需要评委自行体验，再使用局域网或云服务器方案。

## 边界

离线模式适合由团队成员操作演示，不提供给异地老师或评委直接访问。异地访问仍需要稳定的云服务器和固定域名。
