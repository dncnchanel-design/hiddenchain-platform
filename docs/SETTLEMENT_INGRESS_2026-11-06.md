# 新批次演示结算接入

已补齐两方上传新数据、绑定新批次、交易中心创建任务、确定性计算、双方确认、监管复核和归档。保持现有前端布局、原始数据连接器边界、防重复及期间门禁。本轮为本地实现与验收，未提交、推送或部署。

## 协议与边界

- 仅 development/test/demo 支持；production 不启用聚合 Vault 桥接。
- 仅电力发电方 generation→GENERATION_DATA、售电方 supply→RETAIL_DATA。目录资源返回可选 `settlement_asset_type`，界面据此显示。
- 请求与票据 claims 增加可选 `settlement_binding`：`schema_version=connector-settlement-binding-v1`、`trade_batch_no`、`period_start`、`period_end`。请求可省 schema_version，由模型填入固定值；签名中必须包含固定值。
- 批次前后空白清理，长度3–64；日期为严格 YYYY-MM-DD，起止顺序有效，期间不超过366天。
- 绑定上传采用日度 MWh，每日恰一行、完整覆盖声明日期；拒绝小时数据、重复日期、区间外/缺失日期、负数与非有限值。原 CSV value 文本用 Decimal 聚合，最多6位小数，汇总不超过1e12 MWh。
- 回执新增可选 `settlement_summary`：`schema_version=connector-settlement-summary-v1`、与绑定一致的批次及期间、固定映射 `asset_type`、`aggregation=SUM`、`unit=MWh`、十进制字符串 `energy_mwh`、`record_count`、`content_hash`、`claims_hash`、`raw_records_returned=false`。整个回执由连接器 Ed25519 签名。
- 票据绑定 JSON 通过新增迁移持久化，后端验证回执与绑定、源内容哈希、票据 claims_hash、日期/数量、数值规范和已登记公钥。
- 注册回执和创建聚合 DataUpload 同一数据库事务；只将已验证的汇总与来源证据存入 Vault，不接收原始 CSV。平台既有 HMAC 数据引用签名与连接器签名分开保留。
- 同票据/回执幂等返回同一结算引用；修改签名内容、批次、主体或期间必须拒绝。可重试补登记，失败清理本次新建 Vault 文件。
- 新增可选字段缺省时从签名载荷剔除，维持旧票据和普通资源上传兼容。

## 界面

在现有数据连接表单中增加结算选项及批次/日期；上传处理中和回执待恢复时锁定上下文。成功状态显示后端确认的批次、期间和结算引用，并提示双方一致登记后由交易中心创建任务。模板在此模式生成所选期间的空白日度电量行。结算向导按主体、批次、精确期间匹配数据，移除硬编码期间造成的错误预检。

## 验证计划

覆盖旧普通上传兼容、新回执验签/重放/篡改、角色边界、每日完整覆盖与精度、数据库迁移和事务失败恢复；前端表单、上下文恢复及批次期间匹配；独立 demo 栈上传两批新 CSV，正常 HTTP 创建与执行，每批完成确认和审计归档，复核金额并验证重复批次阻断。完成构建、回归和独立审查后填写结果，不预先声称通过。

## 使用方法

1. 发电企业进入“数据连接”，选择“发电量”；售电企业选择“供电量”。
2. 两方均将“用于演示结算”选为“是，绑定结算批次”，填写相同批次及起止日期。
3. 下载空白日度模板，填写每日电量；每日一行，单位 MWh，`value` 不留空，`hour` 不填写。分别直传各自企业连接器，等待“演示结算数据已登记”。
4. 交易中心创建结算任务，填写同一批次、期间及双方主体；数据准备页应显示两份引用“已就绪”。选择规则，创建并启动。
5. 双方确认计算结果，监管批准审计报告后按现有流程归档。已结算的同一批次、期间与参与方仍禁止再次执行。

## 联调修复与保留边界

- 目录新增明确的期间字段，前端兼容旧 `period` 及显式空日期，避免新旧数据误判。
- 聚合引用 UUID 按票据/回执固定；每次事务独占一个随机 Vault 文件，失败只清理本次文件。进程异常中止可能遗留无数据库引用的聚合文件，但不含原 CSV、不阻碍重试，也不会被并发失败请求误删。
- 所有正式数值量化后检查 JSON 数字往返精度，不能精确表达时拒绝计算，不存错误金额。大数反例和“失败后零正式结果、零成功计算”已验证。
- 数据库迁移为新增 `20261106_001`，旧迁移校验和保持；本地栈启动及迁移测试通过。
- 测试顺序问题仅调整 session 客户端及鉴权夹具初始化；保留独立数据库、防覆盖检查和每测试重置，不降低产品密码强度或鉴权门禁。
- 生产环境聚合 Vault 桥接保持关闭。当前计算为应用进程内确定性演示，未新增真实 MPC、TEE 或外部链共识能力；未部署到线上。前端既有大图表 chunk 提示仍存在。
