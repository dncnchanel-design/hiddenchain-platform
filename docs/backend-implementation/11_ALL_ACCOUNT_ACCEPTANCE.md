## 故障与修复

| 已复现问题 | 修复与约束 |
| --- | --- |
| 已知预置目录版本在 2026-08-31 统一到期，历史查询无法执行 | 只修复具有原始标识、哈希、数据引用和截止日的预置版本有效期；保留用户上传、授权期限和历史快照 |
| 首页默认最近 30 日超出预置数据覆盖期 | 与连接器协商最近可用窗口；保留请求截止日、窗口长度、最新版本隔离、最小聚合组及签名兼容 |
| 授权详情切换可能沿用上一记录；交易中心提供方缺少审批入口 | 详情按记录隔离；角色能力同时受实际权限约束 |
| 规则授权到期后无法重新使用；范围与协议额度未完整校验 | 保留历史记录后生成新的规则授权；确认、入队和派发阶段检查日期、地区、资源、函数；串行预留次数并计入绑定协议，幂等重放不重复消耗 |
| 非电力交易中心进入电力专用结算；跨主体复用创建幂等键 | 非电力交易中心使用所属能源受控查询；电力结算入口及服务端都校验能源域和创建权限，幂等返回检查所属主体 |
| TTC 启动、报告审核、异常处置与通知详情路径不完整 | 恢复现有 API 操作，使用相应版本和幂等约束；保留审计关口、双方确认和失败返工条件 |
| 部分助手按钮发送不支持的命令；四类企业读取意图被拒绝 | 快捷按钮使用已有受控命令，补齐企业读取角色并限制本主体；助手不能自行批准写操作 |
| 无法恢复的钱包签名导致 500 | 在签名恢复边界转换明确的签名异常，沿用 401 与失败审计；无效尝试不消耗挑战 |
| 登录页记住账号没有保存行为，网络错误显示成密码错误 | 只保存用户主动选择记住的账号名称；密码和令牌不进入持久存储，显示真实接口错误 |

## 实际能力边界

四个非电力交易中心是对应能源的数据使用方，当前未配置它们自己的物理连接器。可使用目录、申请和受控查询；不虚构本方接入数据。外部钱包绑定、远程 TEE、跨节点 MPC、EDC 运行时和外部链未配置的部分继续保持真实状态，不计作已接入能力。电力计算由固定公式执行，解释服务不可用时仍可完成参数确认和计算，不生成未经执行的正式数值。
