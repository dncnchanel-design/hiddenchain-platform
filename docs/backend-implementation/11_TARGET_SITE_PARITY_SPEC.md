# 目标站复刻与交互闭环规格

## 目标

以 `https://energy-data-space.onrender.com` 的真实页面为交互和视觉基准，在现有 React + TypeScript + FastAPI 工程内复刻 8 项可信数据空间导航。

本规格同时服从两条最终约束：

- 数据目录、隐私计算、身份拓扑保留现有业务逻辑和交互实现。
- 全站所有标题下的说明性、引导性、流程性小字删除，包括白名单页面；技术标识、字段标签、状态值不视为副标题。

## 目标站交互契约

| 页面 | 目标结构 | 业务交互 |
| --- | --- | --- |
| 全局看板 | 6 个指标、山东能源供需态势、地图/趋势、库存仪表、实时审计流、策略分布、连接器状态、协同轨迹 | 看板读取真实后端数据；播放和日期滑块只改变当前视图 |
| 数据问数 | 对话式问数、输入框、发送、示例问题、调用链路和结果 | 发送调用后端解析、策略裁决和受控结果接口；不在前端制造结果 |
| 数据目录 | 保留现有目录、筛选、详情、授权申请流程 | 使用现有真实目录和授权接口 |
| 数据接入 | 连接器、分级、资源元数据、CSV 上传、流程状态、示例 CSV | 上传由 FastAPI 校验、登记、哈希和审计；示例文件由后端返回 |
| 策略中心 | 静态策略矩阵、动态资源策略、授权申请记录 | 读取后端策略矩阵；动态资源规则新增/删除走真实策略接口 |
| 审计存证 | 四项指标、审计流水、存证区块、哈希链状态 | 模拟篡改、恢复、验证链、刷新均走后端并写审计记录 |
| 隐私计算 | 保留现有页面代码和真实任务控制 | 只删除标题下说明性小字 |
| 身份拓扑 | 保留现有页面代码和真实身份拓扑 | 只删除标题下说明性小字 |

## 公共壳

公共壳按目标站真实结构收敛为：深蓝头部、当前身份/DID、退出登录、动态统计栏、白色八项导航、浅色画布。

删除当前壳层中不属于目标站的通知入口、帮助入口、智能助手入口、上下文面包屑栏、快捷查找按钮和额外导航按钮。已有白名单页面仍通过同一鉴权和路由壳进入，不改变其业务状态机。

## 后端边界

新增目标站适配接口只负责页面所需的真实投影，不复制一套前端状态机。接口必须：

- 使用当前 Bearer 会话和组织范围校验。
- 由数据库、策略服务、审计/证据服务或后端演示数据集产生响应，不在前端写死业务数据。
- 写操作接受 `X-Request-ID`、幂等键，并在需要状态版本时接受 `If-Match`。
- 失败响应继续使用 `{ code, message, trace_id, retryable }` 结构。
- 所有上传、规则变更、问数执行、审计控制动作写入可追溯审计记录。

目标适配接口分组：

- `prototype/header`：头部身份与统计投影。
- `prototype/dashboard`：指标、能源态势、库存、审计流和协同轨迹。
- `prototype/query`：自然语言问数解析、裁决和受控结果投影。
- `prototype/connector`：资源列表、CSV 上传和示例 CSV 下载。
- `prototype/policy`：策略矩阵、动态规则新增/删除、授权申请投影。
- `prototype/audit`：审计列表、证据区块、链验证、演示篡改和恢复。

## 按钮与非按钮规则

导航、播放、日期滑块、示例问题填充和抽屉关闭是纯界面操作；它们不得伪装成业务写操作。

除上述纯界面操作外，页面上出现的每个业务按钮都必须能在浏览器回归中观察到对应的 `/api/...` 请求、正确的加载/禁用/错误/成功状态和后端副作用。没有后端能力的按钮不渲染。

## 验收矩阵

- `pnpm tsc --noEmit`
- `pnpm run build`
- `pnpm test`
- `pnpm run lint`
- `pnpm run check:production`
- `pnpm run check:brand-theme`
- 后端全量 `pytest`
- 8 个导航页面逐页浏览器检查：桌面、窄屏、加载、空数据、失败重试和中文可见文案。
- 逐个点击目标站业务交互，记录请求路径、HTTP 状态、界面结果和数据库/审计变化。
- `git diff --check`、远端分支 SHA、Render 健康状态和部署 SHA 分开报告；未取得部署证据时不声称 Render 已完成。
