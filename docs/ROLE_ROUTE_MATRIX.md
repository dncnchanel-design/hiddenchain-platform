## 关键动作

| 动作 | 允许角色 | 额外约束 |
| --- | --- | --- |
| 创建任务 | 交易中心 | 必须恰好选择一个发电主体、一个售电主体和启用规则 |
| 启动结算 | 交易中心 | 数据签名、规则、参与方与授权预检全部通过 |
| 上传/签署数据 | 发电、售电、交易中心 | 发电/售电只能处理本组织允许的数据类型 |
| 创建/启用规则 | 交易中心 | 已启用规则不可静默覆盖 |
| 确认结果 | 发电、售电 | 只能确认本组织 `UNCONFIRMED` 结果；幂等 |
| 创建审计报告 | 监管、管理员 | 只引用已有任务事实与证据 |
| 处置异常 | 监管、管理员 | 测试异常注入在 production 不存在 |
| 查看用户/DID/指标/日志 | 管理员 | 管理控制台专属 |

## 工作台下一步

- 交易中心：优先处理未就绪任务或启动已就绪任务。
- 发电/售电：优先补齐本方数据或确认本方结果。
- 监管：优先复核异常、证据和待审计任务。
- 管理员：优先处理配置、身份、服务和运行异常，不代替业务主体操作。

权限变更时必须同时更新 `frontend/src/access.ts`、`backend/app/routers/auth.py`、对应 `require_roles` 和回归测试。
