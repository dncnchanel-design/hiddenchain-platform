# 开发任务与分工建议

## MVP 已完成

- 前端 A：登录、总览、角色工作台、五角色菜单与字段权限提示。
- 前端 B：数据调用、用途控制、场景验证、隐私计算、结果回执、存证、审计、Agent、异常、日志、系统、报告、指标页面。
- 后端 A：用户、组织、DID、数据引用、规则、任务、结果、证据和日志模型。
- 后端 B：六 Agent 双闭环、四场景耦合、自动结算、用电隐私分析、三阶段存证、证据问答。
- 安全：PBKDF2、JWT、RBAC、主体域隔离、哈希承诺、HMAC 演示签名、工具白名单。
- 测试：身份返回脱敏、角色越权、四场景完整结算、VPP偏差修正、调度安全闸门、链证据验真、隐私聚合、证据约束问答。

## 文献对齐增强（本版已完成）

- 轻量 HCDS-1.0 Connector：目录发现、DID/VC 互认、合同协商、协议状态和回执关联。
- 电力数据产品目录：统一数据产品 ID、语义标识、Schema、单位、时间粒度、质量和用途元数据。
- 使用控制：按主体、用途、算法、有效期、执行环境、输出模式和使用次数执行 PEP/PDP 风格判定。
- 可验证回执：将协议 ID、使用决定、输入承诺、结果哈希和原始数据导出标记写入 ComputeReceipt 与证据事件。
- 页面验收：以“可信数据调用”为一级入口，展示目录、协议能力、协商协议和回执状态；以“隐私计算”为一级入口展示策略、执行与回执。

## 下一阶段并行任务

| 工作包 | 负责人建议 | 输入 | 交付与验收 |
| --- | --- | --- | --- |
| EDC 接入 | 数据空间组 | `MockDataSpaceAdapter` 接口 | 双 Connector 完成目录发现、合同协商和传输许可 |
| OPA 策略 | 安全组 | DataContract/ODRL 字段 | Rego 策略覆盖用途、主体、算法、时效；拒绝事件留痕 |
| SecretFlow/MPC | 隐私计算组 | `DataPermit`、`RulePackage` | 两机构节点完成 PSI 与联合结算，生成兼容回执 |
| 联邦学习/DP | 算法组 | 新能源预测 ComputePlan | 多方训练不汇聚样本，对外预测结果满足披露策略 |
| HEU/秘密共享 | 隐私计算组 | VPP 资源池 DataRef | 聚合可调能力，不返回单户负荷或设备能力 |
| TEE安全校核 | 电力业务组 | 调度边界承诺、剩余偏差 | 在可信执行环境调用经过验证的安全约束服务，拒绝分支可复现 |
| FISCO BCOS | 区块链组 | `BlockchainEvidence` | 证据合约部署、SDK 写链、交易回执核验 |
| DID/VC | 身份组 | `MockDidAdapter` | 主体与 Agent 凭证签发、吊销和能力令牌校验 |
| 规则 RAG | Agent 组 | 规则来源引用 | 条款切分、混合检索、引用校验；不得直接修改 DSL |
| 四场景模型 | 电力业务组 | 预测、交易、VPP、调度演示适配器 | 接入预测评估、偏差响应、网络约束和结算规则回归用例 |
| 结算规则扩展 | 电力业务组 | `formula_dsl` | 增加峰谷、偏差、绿电、辅助服务等可配置规则与回归用例 |
| UI 演示优化 | 前端组 | 现有 17 模块 | 加入真实节点状态、演示脚本模式和错误恢复状态 |
| 部署观测 | 平台组 | Docker Compose | K8s、OpenTelemetry、Prometheus、密钥托管 |

## 联调顺序

1. 保持现有适配器接口不变，先让真实 EDC 返回兼容 `DataPermit`。
2. 先用真实 PSI/MPC 替换市场结算适配器，再并行接入联邦学习、HEU 与 TEE 场景适配器。
3. 将调度安全闸门替换为经电力专业人员校核的约束模型，保留拒绝语义和证据格式。
4. FISCO BCOS 接收三阶段证据载荷并返回真实 `tx_hash`、`block_height`。
5. DID/VC 和 OPA 替换模拟校验，跑通拒绝、越权、凭证吊销和调度校核失败场景。
6. 运行后端测试与前端构建，再按答辩脚本执行四场景完整闭环和异常分支。
